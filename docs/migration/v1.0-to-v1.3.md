## New L2 gates (cumulative)

If you previously claimed **L2** on v1.0, re-verify **all** gates in [l2-gates.md](../l2-gates.md). New since v1.0:

- v1.1: NG1, NG2, A1 (new definition), TS8
- v1.2: S1, S2, S5, T1 depth, T8, P1 (axe CI), P11
- v1.3: SaaS5, U4, U11, D3 (≥6.5), D6, D10

## Self-assessment update steps

1. Change header: `Rubric version: Quality Framework v1.3` (or v1.4 after docs release).
2. Add rows for new IDs (SaaS8–12, U11–13, D9–10, S11, P11, T12–14 if applicable).
3. Expand **demo vs production** table (S1, S5, P1, T1).
4. Re-calculate category scores per [scoring.md](../scoring.md).
5. Update badge only if **L1 Must** and **L2 gates** still Pass.
6. Link evidence URLs for D10.
