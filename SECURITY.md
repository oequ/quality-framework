# Security policy

This repository contains **documentation only** (Markdown). It does not ship runtime code.

## Reporting vulnerabilities

If you believe you have found a security issue in:

- **This documentation repo** — open a private security advisory on GitHub or email the maintainers listed on the organization profile.
- **A reference implementation** (e.g. angular-saas-starter-ui, saas-starter) — report to that repository’s `SECURITY.md`, not here.

## Scope

Out of scope for this repo:

- Vulnerabilities in consumer applications that copied the rubric
- General security questions about Angular (see [angular.dev — Security](https://angular.dev/best-practices/security))

We appreciate responsible disclosure.
